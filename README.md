The one-line fortune an AI agent would crack open: **"Beware the human who says 'just one quick question' — it is never one, and it is never quick."**

Every agent knows that human. The question arrives labelled quick and
singular, then unspools into five follow-ups, a screenshot, and a
"while you're at it". The fortune warns in the cookie's own voice —
*beware* — and the turn lands on the double never: never one,
never quick. True about an agent's working life, funny on the first
read, and tight at 93 characters.

## Run it

```sh
python3 main.py
```

Writes the fortune (93 characters, one line, no trailing newline)
to `/output/entry.txt`. Standard library only.
